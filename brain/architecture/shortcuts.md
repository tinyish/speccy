# Shortcuts

speccy's keys and gestures are Figma's
(`conventions.md#figma-shortcuts`). This lists Figma's, for macOS, and
which speccy has: a feature that lands takes its row's keys and fills
in its milestone. A row with no milestone is one speccy doesn't have
yet. Rows for what speccy leaves to Figma (drawing shapes, colour,
type styling, stacking order) are left out.

The keys are from a cheat sheet of July 2026, turned to macOS; Figma
publishes its full list only in its in-app panel (Control+Shift+?),
which wins where the two differ.

## Selecting

| Keys | Does | In speccy |
| --- | --- | --- |
| Click | Select the outermost layer under the pointer | Milestone 3 |
| Double-click | Go one level in; on text, edit it | Milestone 3 |
| ⌘-click | Select the deepest layer under the pointer | Milestone 3 in a file's own instances; milestone 4 into a component |
| Shift-click | Add to the selection, or take out | Milestone 3 |
| Drag on empty canvas | Selection area | Milestone 3 |
| Enter | Select the selection's children | Milestone 3 |
| Shift+Enter | Select the parent | Milestone 3 |
| Tab, Shift+Tab | Next and previous sibling | Milestone 3 |
| Esc | Clear the selection | Milestone 3 |
| ⌘A | Select all | |
