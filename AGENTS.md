# The project

speccy is an agentic-first UX spec tool for product teams whose UI is
built mostly by coding agents: one visual spec that designers and agents
both write, linked to the code, that shows where the implementation drifts
from it. Its stack is chosen at the architecture step. What it is and for
whom lives in `brain/prd/seed.md`; how it is set up and run, in
`README.md`. How work is done is the shared process, loaded in every
session.

`brain/architecture/core.md` is kept in sync by hand: a change that alters
what it describes updates it in the same change.
